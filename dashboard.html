Receita e produtos

Onde o faturamento nasce — e por quê. Perguntas 1, 4 e 10.

Pergunta 1

Clothing concentra 44,7% da receita — por volume, não por preço

O ticket médio é quase igual entre categorias ($57–60); a liderança vem das 1.737 transações de Clothing.

SQL + dados
SELECT "Category",
       SUM("Purchase Amount (USD)") AS receita_total,
       ROUND(AVG("Purchase Amount (USD)")::numeric, 2) AS ticket_medio,
       COUNT(*) AS qtd_compras,
       ROUND(SUM("Purchase Amount (USD)") * 100.0 /
             (SELECT SUM("Purchase Amount (USD)") FROM shopping_trends), 2) AS participacao_pct
FROM shopping_trends
GROUP BY "Category"
ORDER BY receita_total DESC;
Pergunta 4

Demanda pulverizada: os 25 itens vendem entre 124 e 171 unidades

Empate triplo no topo (Blouse, Jewelry e Pants, 171 cada). Dress tem o maior ticket do top 10 ($62,17); Jacket, o menor ($56,74).

SQL + dados
SELECT "Item Purchased",
       COUNT(*) AS qtd_vendas,
       ROUND(AVG("Purchase Amount (USD)")::numeric, 2) AS ticket_medio,
       SUM("Purchase Amount (USD)") AS receita_total
FROM shopping_trends
GROUP BY "Item Purchased"
ORDER BY qtd_vendas DESC, "Item Purchased"
LIMIT 10;

Pergunta 3

A faixa 56–70 anos é a mais ativa (28,3% das compras)

O ticket médio é uniforme entre faixas ($59–61): a idade influencia a frequência, não o valor por transação.

SQL + dados
SELECT CASE
         WHEN "Age" BETWEEN 18 AND 25 THEN '18-25'
         WHEN "Age" BETWEEN 26 AND 35 THEN '26-35'
         WHEN "Age" BETWEEN 36 AND 45 THEN '36-45'
         WHEN "Age" BETWEEN 46 AND 55 THEN '46-55'
         ELSE '56-70'
       END AS faixa_etaria,
       COUNT(*) AS qtd_compras,
       ROUND(AVG("Purchase Amount (USD)")::numeric, 2) AS ticket_medio,
       SUM("Purchase Amount (USD)") AS valor_total
FROM shopping_trends
GROUP BY faixa_etaria
ORDER BY faixa_etaria;
Pergunta 11

Frequência de compra não muda o ticket ($58,97–$60,69)

Grupos equilibrados (539–584 clientes). Nota de qualidade: Bi-Weekly ≈ Fortnightly e Quarterly ≈ Every 3 Months são rótulos redundantes.

SQL + dados
SELECT "Frequency of Purchases",
       COUNT(*) AS qtd_clientes,
       ROUND(AVG("Purchase Amount (USD)")::numeric, 2) AS ticket_medio
FROM shopping_trends
GROUP BY "Frequency of Purchases"
ORDER BY CASE "Frequency of Purchases"
    WHEN 'Weekly' THEN 1 WHEN 'Bi-Weekly' THEN 2
    WHEN 'Fortnightly' THEN 3 WHEN 'Monthly' THEN 4
    WHEN 'Quarterly' THEN 5 WHEN 'Every 3 Months' THEN 6
    WHEN 'Annually' THEN 7 END;
Pergunta 14

Fidelidade quase não prevê assinatura: sobe até 29,5% e cai

% de assinantes por faixa de compras anteriores. A tendência sobe até 31–40 e quebra na faixa 41–50 — histórico sozinho não é bom preditor.

SQL + dados
SELECT CASE
         WHEN "Previous Purchases" BETWEEN 1 AND 10 THEN '1-10'
         WHEN "Previous Purchases" BETWEEN 11 AND 20 THEN '11-20'
         WHEN "Previous Purchases" BETWEEN 21 AND 30 THEN '21-30'
         WHEN "Previous Purchases" BETWEEN 31 AND 40 THEN '31-40'
         ELSE '41-50'
       END AS faixa_compras,
       COUNT(*) AS total_clientes,
       ROUND(AVG(CASE WHEN "Subscription Status" = 'Yes'
                      THEN 1 ELSE 0 END) * 100, 2) AS pct_assinantes
FROM shopping_trends
GROUP BY faixa_compras
ORDER BY faixa_compras;

Compras por estação

Ticket médio (US$)

Variação pequena entre estações (999 vs 955 compras): não há sazonalidade marcante — consumo estável o ano todo.

       COUNT(*) AS qtd_compras,
       SUM("Purchase Amount (USD)") AS receita_total,

Pergunta 13

Cada estação tem sua paleta: as 5 cores mais vendidas

Silver no verão é o maior pico individual (59 vendas). Olive aparece no top de duas estações — a escolha mais versátil.

SQL
WITH ranked AS (
    SELECT "Season", "Color", COUNT(*) AS qtd,
           ROW_NUMBER() OVER (
               PARTITION BY "Season"
               ORDER BY COUNT(*) DESC, "Color"
           ) AS rank
    FROM shopping_trends
    GROUP BY "Season", "Color"
)
SELECT "Season", "Color", qtd
FROM ranked
WHERE rank <= 5
ORDER BY "Season", qtd DESC, "Color";

Nem desconto nem preço movem a satisfação

As 1.677 compras com desconto usaram promo code — e vice-versa. Diferença de ticket de $0,85; correlação entre valor pago e avaliação praticamente nula.

Segmentação por gasto

Quartis de valor de compra e o perfil de cada segmento. Pergunta 15.

Pergunta 15

Quatro quartis de gasto, um único perfil de cliente

Idade, gênero, assinatura e avaliação são praticamente iguais nos quatro segmentos — e Clothing lidera em todos. O valor da compra depende do produto escolhido, não do perfil demográfico. Quartis via pd.qcut, replicados em SQL com PERCENTILE_CONT.

SQL
WITH limites AS (
    SELECT PERCENTILE_CONT(0.25) WITHIN GROUP (ORDER BY "Purchase Amount (USD)") AS q1,
           PERCENTILE_CONT(0.50) WITHIN GROUP (ORDER BY "Purchase Amount (USD)") AS q2,
           PERCENTILE_CONT(0.75) WITHIN GROUP (ORDER BY "Purchase Amount (USD)") AS q3
    FROM shopping_trends
),
quartis AS (
    SELECT s.*,
           CASE
             WHEN s."Purchase Amount (USD)" <= l.q1 THEN 1
             WHEN s."Purchase Amount (USD)" <= l.q2 THEN 2
             WHEN s."Purchase Amount (USD)" <= l.q3 THEN 3
             ELSE 4
           END AS quartil
    FROM shopping_trends s
    CROSS JOIN limites l
)
SELECT CASE quartil WHEN 1 THEN 'Economico' WHEN 2 THEN 'Moderado'
                    WHEN 3 THEN 'Alto' ELSE 'Premium' END AS segmento,
       '$' || MIN("Purchase Amount (USD)") || ' - $' ||
       MAX("Purchase Amount (USD)") AS faixa_valor,
       ROUND(AVG("Purchase Amount (USD)")::numeric, 2) AS ticket_medio,
       MODE() WITHIN GROUP (ORDER BY "Category") AS categoria_top
FROM quartis
GROUP BY quartil
ORDER BY quartil;

Conclusão geral

O dataset apresenta distribuições surpreendentemente uniformes em quase todas as dimensões: gênero, idade, frequência, pagamento, frete e estação não são fortes preditores do valor de compra. Para modelagem preditiva eficaz seria necessário coletar sinais adicionais — histórico de navegação, tempo no site, campanhas vistas. Enquanto isso, as alavancas mais promissoras são reformular a proposta da assinatura (27% de adesão sem diferencial de comportamento) e a curadoria de cores por coleção sazonal.
